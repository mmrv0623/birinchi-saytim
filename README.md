# ML // Network — Admin Control Suite

Ultra-premium futuristic ML Admin Management Dashboard.

A cyberpunk-styled, AAA-gaming-control-panel-inspired admin & curator management system built with Next.js 16, React 19, Tailwind v4, Framer Motion, Three.js (React Three Fiber), Zustand, and Recharts.

See open PRs for the full implementation.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
